# Lens 02 — Utility + Scale Discovery (IMDb / TMDB / JustWatch / Rotten Tomatoes / Metacritic)

## VERDICT (3 sentences max)
BollyAI is being graded against products people open with their wallet already half-out ("is it worth it / where do I watch it"), and right now it answers neither question above the fold - the homepage is a magazine bento, not an answer surface, and the **title page** (the page that actually ranks and converts) is not even the thing being redesigned. Win by fusing IMDb's *authority chrome* (score-stack rail at the top, key-facts rail, "where to watch" block) with a critic's *verdict and voice* - BollyMeter as ONE honest editorial number shown with its visible basis, sitting exactly where IMDb puts its crowd-rating but feeling earned, not crowdsourced. The single biggest unbuilt lever is the **"Where to watch X in India" programmatic page** - JustWatch's ~20M-page wedge - which BollyAI can own for Indian OTT because no incumbent does India's provider mix (JioHotstar/SonyLIV/ZEE5/Aha/SunNXT) with a verdict attached.

## WHAT THE BEST DO  (named examples + the MECHANISM)
- **Score-stack rail pinned at the very top, before synopsis** — *IMDb (rating chip top-right of the title block), JustWatch (a horizontal strip of "JW Score 95% · IMDb 8.4 (725k) · PG-13 · 2h47")* — the number is the first contract with the user; it answers "should I care?" in <1s, and only THEN does the page spend the user's attention on plot. Psychology: decision-cost is paid up front, so the rest of the page reads as justification, not homework. BollyAI buries its verdict inside a card plate; it should be the masthead of every title page.
- **Provider grid split by monetization (Stream / Free / Rent / Buy / Cinema)** — *JustWatch* — the "All / Subscription / Free / Rent / Buy / Cinema / Disc" filter row + a logo grid with type badge, price, and 4K/HD quality chips. Mechanism: it collapses the user's real next action ("ok, where, and does it cost me?") into one scannable block. This is the **utility moat** — IMDb/RT have weak where-to-watch; a *verdict + India-correct where-to-watch* on one page is a combination none of the five incumbents ship.
- **Key-facts rail (scannable, label:value, monospaced)** — *IMDb (Director / Writers / Stars / Release / Runtime / Box office in a tight stack), TMDB (Status / Original Language / Budget / Revenue / Keywords sidebar)* — fast facts in a fixed-position rail let a returning user re-confirm a title in 3 seconds without reading prose. BollyAI already ships JetBrains Mono for numbers — this rail is a native fit and currently absent as a *consistent* element.
- **Trust shown as composition, not assertion — sample size + the critic/audience split** — *Rotten Tomatoes (Tomatometer % beside "based on N reviews", Certified Fresh needs >=80 reviews; separate Audience Score from verified ticket buyers), Metacritic (weighted 0-100 + "based on N Critic Reviews", Metascore color band green/yellow/red)* — a single number feels *earned* only when its denominator is visible. RT/MC never show a bare score; they show score **+ basis + count**. This is precisely BollyAI's honesty fence (editorial `reviewRating` + visible basis, NO `AggregateRating`) — so BollyAI's constraint is actually its credibility design: BollyMeter must always render its `basis` string and a "what this is" disclosure inline, the way MC renders its denominator.
- **The colored verdict band as instant semantic read** — *Metacritic green/yellow/red Metascore* — color does the verdict before the digit is even parsed; a 41 in red is understood before you read "41". BollyAI has per-desk OKLCH accents but no *verdict-state* color ramp (e.g., 8+ = a confident warm gold, 5-6 = muted amber, <4 = a cooled desaturated state). The number should change temperature with its own value.
- **"More like this" rail that keeps the session alive** — *IMDb / TMDB "Recommendations" / JustWatch "Similar Titles"* — a horizontal poster rail of adjacent titles at the bottom of every detail page converts a dead-end ("seen it / not interested") into a next click. Mechanism: at the moment of decision-completion the user has *spare intent*; the rail catches it. This is the cheapest dwell-time lever and is build-time-computable (genre/desk/era adjacency) — perfect for static export.
- **Faceted discovery at scale — filter the catalog, don't just list it** — *JustWatch (filter by genre / release year / price / provider / rating), TMDB (Discover with sortable + multi-facet)* — incumbents treat the catalog as a queryable database, not a feed. BollyAI's homepage is 10 stacked editorial rails with zero user agency; there is no "show me 2026 Telugu films rated 7+ on SonyLIV" path. Faceting is what makes a 1000-title library feel like a *tool* instead of a magazine.
- **Streaming-charts / trending rank as live social proof** — *JustWatch ("#438" with a +/- trend arrow), TMDB popularity* — a live rank with a movement arrow manufactures "everyone is deciding on this right now" urgency without a single fake number. BollyAI has real box-office data and freshness stamps — a "Trending on OTT this week, rank +N" derived from its own traffic/recency is honest and on-brand.

## WHERE BOLLYAI FAILS TODAY  (grounded in screenshot / live site / code)
- **The homepage answers neither core question above the fold.** The screenshot shows three near-equal-weight tiles (Karuppu lead, Game of Thrones, Dhokda) — but no verdict number on the lead, no "where to watch," no single thing the eye is *told* to land on. IMDb/JustWatch put the score and the providers first; BollyAI puts a bento mosaic first. The hero is real estate spent on *layout* instead of on *the answer*.
- **The verdict is demoted to a card sub-element.** BollyMeter (the entire differentiator) lives inside `MosaicTile`/`MediaCard` as a "compact verdict meter" plate — small, low-contrast, competing with poster + type badge + New flag + box-office figure. The one thing only BollyAI has is rendered like the *least* important element. (Live fetch confirms films show only a BO range, no BollyMeter at all on theatrical — so the lead tile Karuppu shows money, not a verdict.)
- **Inconsistent score grammar across types.** Series get "8.4/10"; films get a BO range with status labels (TRACKING / DISASTER / ALL-TIME). A user cannot scan one consistent "how good is it" signal across the wall — the trust-anchor (a stable, always-present number with a basis) that RT/MC/IMDb never break is broken here. Theatrical needs a BollyMeter too (or a clearly-labeled "verdict pending — in cinemas" state), not a vacuum.
- **No basis / denominator visible = the honesty fence is invisible, so it can't build trust.** The fence (basis string, no AggregateRating) is the credibility *asset*, but on the homepage the score is a bare "8.4/10" with no "based on…" anywhere in view. RT/MC make the score feel earned by always showing the count; BollyAI hides its (better, editorial) basis behind a click. The trust signal exists in the data and is wasted in the UI.
- **The title page — the actual money/SEO surface — is out of frame.** IMDb/JustWatch/RT live or die on the *detail* page; that is what ranks for "X review" and "where to watch X." The redesign brief is homepage-centric, but for this lens the title-page anatomy (score-stack + key-facts rail + provider block + more-like-this) is the higher-leverage fix and is currently a card-plate's worth of structure, not a page.
- **Zero faceting / zero user agency.** Ten editorial rails, no filter, no "more like this," no sort. The site is a feed you scroll, not a tool you query — the opposite of how people use IMDb/JustWatch/TMDB to *decide*. Library scale (the South-first 1000+ title ambition) will read as noise without facets.
- **Monogram placeholders read as "data missing" on the exact pages meant to look authoritative.** IMDb never shows an empty poster; the absence is itself a downgrade signal on a *cinema* surface. (Mitigation belongs to other lenses, but this lens flags that on title/where-to-watch pages a placeholder poster directly undercuts the authority posture.)

## TOP 5 CONCRETE CHANGES  (ranked; implementable)
1. **Ship a real title-page "score-stack masthead" component (`<VerdictMasthead>`).** A full-width band directly under the backdrop, before synopsis: left = **BollyMeter as the hero number** in Fraunces at `clamp(3rem, 6vw, 5rem)`, colored by a verdict-temperature ramp (8+ warm gold `oklch(80% .15 75)`, 6-7.9 amber, 4-5.9 muted, <4 cooled `oklch(60% .04 280)`); immediately under it the **`basis` string** in `--text-dim` ("Basis: strong Telugu trade word-of-mouth; RT 88% / 42 critics") and a small "What is BollyMeter?" disclosure chip; right = a monospaced **key-facts rail** (Desk · Language · Runtime · Release · Director · Lead · BO trade-estimate). This puts the verdict where IMDb puts its rating and makes the honesty fence *visible* as trust. No `AggregateRating` — the basis line IS the denominator.
2. **Build the "Where to Watch in India" provider block (`<WatchProviders>`) and its programmatic page.** On every title page: a filter row (`All / Stream / Free / Rent / Buy / In Cinemas`) + a grid of India provider chips (JioHotstar, Netflix, Prime Video, SonyLIV, ZEE5, Aha, SunNXT, Manorama Max) each with type badge + quality (4K/HD) + deep-link. Sourced via the **TMDB watch-providers API at BUILD TIME** (metadata/attribution path — allowed; the CLAUDE.md fence bans the *scrape* path and serving JustWatch/TMDB *images*, so use TMDB provider names + your own self-hosted provider logos/wordmarks). Then generate static `/watch/<title>` and desk roll-ups `/where-to-watch/telugu-movies-on-sonyliv` — JustWatch's 20M-page wedge, India-correct, **with a BollyMeter verdict attached** (the thing JustWatch can't do). This is the discovery+utility moat and it is 100% static-export-compatible.
3. **Promote BollyMeter on the homepage lead and standardize score grammar.** On the FeaturedMosaic lead tile, render BollyMeter as a large temperature-colored chip top-left of the backdrop (IMDb/JustWatch pattern: score before everything), and add a BollyMeter (or explicit "Verdict: in cinemas / pending" state) to *every* card including theatrical — never let films show only money. One consistent "how good is it" token across films and series so the wall is scannable as a verdict grid, not a mixed-signal collage.
4. **Add a faceted "Browse / Discover" surface and a "More Like This" rail.** (a) A `/browse` route with client-side facets (Desk, Language, Year, Provider, BollyMeter band, Film/Series) over the build-time JSON index — instant, no server, turns the library into a tool. (b) A `<MoreLikeThis>` poster rail at the bottom of every title page, computed at build time from desk + genre + era adjacency, to kill dead-ends and extend the session. Both are static-export-native and directly lift dwell time.
5. **Make the trust basis a reusable, always-present primitive (`<VerdictBasis>`).** Wherever a BollyMeter renders (card, masthead, rail), a one-line basis + source-count must render with it (RT/MC "based on N" discipline), and a global "How BollyMeter works / BollyAI has not watched anything…" trust page linked from every score. This converts the honesty constraint from an invisible build-gate into the brand's visible credibility chrome — the editorial answer to RT's sample-size and the moat against "AI made this number up."

## LATEST TECH / UI NOTE  (within static-export + ₹0 fence)
- **View Transitions API (cross-document, 2026-baseline in Chromium/Safari).** Poster-grid → title-page morph (the poster scales into the masthead backdrop) with `@view-transition { navigation: auto }` + `view-transition-name` on the poster — zero JS, pure CSS, degrades to a normal nav. This is the single highest-impact "feels like latest UI" upgrade and is free on static HTML — exactly the IMDb/JustWatch tap-poster-to-detail flow but cinematic.
- **`content-visibility: auto` + `contain-intrinsic-size`** on every off-screen rail/card to keep a long faceted catalog buttery — the scale-rendering trick the incumbents need server-side, you get client-side for free.
- **CSS-only scroll-snap rails with `scroll-snap-stop`** for the provider/more-like-this/just-dropped rails — premium horizontal feel, no JS carousel lib (keeps the ₹0 / no-animation-library fence).
- **Build-time JSON → static facet index** (a tiny prebuilt inverted index shipped as JSON, filtered client-side) so `/browse` faceting is instant without a DB. JustWatch-grade discovery, statically.
- **`color-mix()` + OKLCH** to derive the verdict-temperature ramp and the Metascore-style color band from your existing tokens — no new palette, just a function over `--accent`.
- Keep `JSON-LD reviewRating` (single editorial rating, `Review` type) — *correct* for the no-AggregateRating fence and it wins the Google rich-result that RT/IMDb get, honestly.

## ANTI-SLOP WARNING  (the generic redesign trap for THIS lens)
- **Do NOT clone IMDb's grey-on-white database chrome.** IMDb is *neutral by design* and visually forgettable; copying its layout literally would throw away BollyAI's only edge (verdict + voice + dark cinematic OKLCH skin). Borrow IMDb's *information hierarchy* (score-stack, facts rail, where-to-watch), render it in BollyAI's bespoke art direction — never its flat utilitarian skin.
- **Do NOT fake the trust signals you don't have.** The temptation when emulating RT/MC is to manufacture a "94% · 1,204 ratings" social-proof block. That detonates the honesty fence and the brand. The win is the *opposite*: ONE editorial number with an honest, specific basis line — make scarcity of fake votes a feature ("we don't crowdsource, we read everyone who has").
- **Do NOT bolt on five external logos as borrowed authority.** Showing IMDb/RT/MC scores beside BollyMeter (à la JustWatch's score strip) is tempting but (a) dilutes BollyMeter as *the* number and (b) risks the TMDB/IMDb data/image fences. Cite RT/MC *inside the basis line* as text attribution, not as a competing scoreboard.
- **Do NOT build faceting as a heavy SPA.** No client-side router, no 200KB filter framework — a static JSON index + vanilla filter keeps the fence. The slop move is reaching for a UI kit to do what `Array.filter` + CSS does.
- **Do NOT let the provider block become a generic affiliate wall.** JustWatch's grid can feel like an ad unit; keep BollyAI's editorial frame (verdict sits above the providers — "here's our faisla, and here's where to get it") so utility serves the verdict, not the other way around.

## ONE BIG SWING  (the "kamaal" move only this lens sees)
**Own "Where to watch X in India — and is it worth it?" as a category no incumbent ships.** JustWatch tells you *where*; IMDb/RT tell you *how good* (US-centric, weak on Indian OTT and South cinema); **nobody fuses both for the Indian provider mix.** Build the programmatic `/watch/<title>` + `/where-to-watch/<facet>` estate (JustWatch's 20M-page wedge, scoped to India's real services — JioHotstar/SonyLIV/ZEE5/Aha/SunNXT/Manorama Max) where every page leads with the **BollyMeter verdict** and then the **India-correct provider grid**, both static, both honest. The page's one-line promise — *"BollyAI hasn't watched it, but here's the faisla and exactly where to stream it in India"* — is a search-intent BollyAI can dominate (the South-first OTT long-tail is wide open, and it's *decision* traffic, the highest-converting kind). It turns the honesty fence into the headline, weds the differentiator (verdict + voice) to the incumbents' utility (where-to-watch at scale), and is buildable entirely within static-export + ₹0. This is the discovery moat the orchestrator's own notes flag as BollyAI's biggest unbuilt lever — shipped as the spine of the site, not a feature.
